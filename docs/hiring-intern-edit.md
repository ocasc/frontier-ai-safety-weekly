# 前沿 AI 安全双周刊 编辑实习生招募

OCASC（AI 安全开放社区）招一到两名实习生，编辑我们的中文 AI safety 双周刊。

|  |  |
|---|---|
| **人数** | 一到两人 |
| **地点** | 远程，在上海可以来线下 |
| **时间** | 每周 6 到 10 小时，至少三个月 |
| **报酬** | 实习补贴，按阶段定 |
| **语言** | 中文写得清楚，英文论文读得动 |
| **证明** | 可开实习证明 |
| **报名** | [报名表](https://wj.qq.com/s2/28521902/2n7h)，两分钟 |

## 这份刊物

每两周一期，九篇短文做成一张公众号长图，同一份材料再录一期十分钟的播客。选题来自那两周读到的东西：新出的 arXiv 论文、实验室发布的模型卡和系统卡、评估报告。社群六百多人，读者一万多。

每篇的初稿由我们的流程自动出，脚本加模型。实习生的活从初稿之后开始。

## 你要做的

- 每个数字回到论文里核一遍。出处追不到的，删掉
- 中文读着像翻译的地方，改成人话。读者认识的术语用中文，中文里还没定下译名的留英文
- 读者缺背景会看不懂的地方，补一句。一般一句就够
- 标题不能比研究结论许更大的愿
- 长图和播客稿要说同一件事

## 之后能走到哪

头两期你和我们一起做。第三期起自己跑一期：定这一期写哪几条，排标题，交排版，发布。发之前我们看一遍。这样跑过几期，可以固定负责一个板块，或者接管整条流程、带新人。能一个人把一期撑下来，就轮到这份刊物本身：选题方向、作者和嘉宾的联系。

## 你能拿到

- 三个月六七期，留下来一年二十六期
- 作品公开发表
- 每一期发之前，有人跟你逐句过一遍
- 补贴和实习证明
- 找下家时我们写推荐、帮忙介绍
- OCASC 的课程和研讨会，团队成员都能参加

## 我们在找谁

- 中文写得清楚。不要求漂亮
- 读英文论文不用先翻一遍
- 每周 6 到 10 小时，至少三个月
- 写过东西。文章、报告、翻译都算，研究背景也认
- 不用预先懂 AI 安全

## 报名

填[报名表](https://wj.qq.com/s2/28521902/2n7h)，中文，两分钟。贴一两篇你写过的中文科技类文章，再给一个 LinkedIn、个人主页或 CV 的链接。

一周内回复。合适的话，我们发一张真实的卡片给你改，两边看看合不合手。

报名陆续看，招到为止。

## 关于 OCASC

OCASC 是一个中文 AI 安全社区，成员有研究者、工程师，也有政策和法律背景的从业者。社区办课程（BlueDot Impact 课程的中文版）、论文研读、研讨会和线下聚会。更多见 [aisafety-cn.com](https://aisafety-cn.com/) 与 [github.com/ocasc](https://github.com/ocasc)。
